# Muhammad Ikram — Spatial Glass Portfolio

A React + Vite implementation inspired by the supplied floating-glass spatial portfolio reference.

## Run
```bash
npm install
npm run dev
```

The project is configured for **localhost:5180**. Change `server.port` in `vite.config.ts` if that port is already occupied.

## Stack
React, TypeScript, Vite, React Three Fiber, Three.js, Drei, GSAP-ready spatial styling, Framer Motion, Lenis, Matter.js and Lucide.
